# 队员协作与验收说明

## 共享范围

本仓库包含可运行的本地演示网页、6 张测试图片、图片来源与授权说明、百炼 Agent 编号和版本配置。它不包含任何账号密码、APP_KEY 或真实派遣能力。

## 运行前提

- Node.js 18 或更高版本。
- 校园网环境，能够访问百炼平台。
- 有权限的百炼 `BAILIAN_APP_KEY`（通过私密方式向组长获取或自行创建，绝不提交仓库）。

## 验收步骤

0. 先跑本地自动化测试：`npm test`。它不需要密钥也不联网，全绿说明本地链路没问题；如果这一步就红了，不要继续往下排查平台。
1. 按根目录 README 创建本机 `.env.local` 并运行 `npm run demo`。
2. 在 `http://127.0.0.1:8789` 准备巡检图片，二选一：
   - 上传本机 JPG/PNG（需要已配置对象存储，见 `docs/上传与对象存储配置.md`）；
   - 或选择自带测试素材并确认预览图出现。
3. 确认“公网图片链接”里是一个公网可访问的直链。素材清单里没有配置直链的测试图只能预览，此时请改用上传或自行粘贴直链。
4. 点击“启动真实巡检研判”，等待结果；预期可看到任务规划、视觉识别、风险研判和人工复核四个已激活步骤。
5. 点击“确认生成模拟工单”，确认出现 jfg4 返回的工单编号和“待人工审批”。
6. 选择审批通过、驳回或退回复飞核验，并验证可撤销当前决定后重新选择。

## 调用失败怎么判断该找谁

失败信息统一带 `【stage】`、排查提示和非敏感诊断信息（不会输出密钥或完整响应）。

- `config.missing_key` / `input.invalid` / `image.*` / `upload.*`：本地问题，按提示自己修。
- `createSession.network` / `.timeout`：本机到平台的网络问题，先查校园网。
- 信息里写明“平台侧故障（external blocker），本地代码与本机配置无需修改”时，就不要改本地代码。典型例子是平台后端数据库只读导致的
  `cannot execute INSERT in a read-only transaction`（`INSERT INTO ibp_agent_session`），会被归为 `createSession.rejected` 并标注平台故障，只能等平台恢复或联系平台维护方。
- `run.empty` 表示平台返回成功但没有文本输出。先确认图片直链能在浏览器里无登录打开，再检查工作流是否有文本输出节点。

stage 对照表见根目录 README。

## 测试图片说明

- `01`、`02`：桥梁漂浮物/杂物堆积场景，用于风险分级对比。
- `03`：道路积水场景，已经完成百炼真实调用验证。
- `04`：低清晰度派生样例，预期建议复飞核验而不是强行判定。
- `05`、`06`：正常道路/桥梁，适用于误报检查。

图片原始来源、署名和许可见 `assets/test-images/README.md`；素材清单与公网直链见 `assets/test-images/test-image-catalog.json`（唯一来源，源码不再重复维护 URL 映射）。

清单里的 `publicUrl` 只允许填写自己可控、长期有效的对象存储直链。临时图床（uguu.se 等）直链会在数小时到数天内过期，服务启动时会拒绝并告警。`publicUrl` 为空的素材只能在本页预览，平台读不到本机 `127.0.0.1` 地址。

## 安全边界

平台调用生成的是风险研判、人工复核记录和模拟工单；任何审批按钮都不会启动真实无人机、人员或设备派遣。

密钥与凭据：`BAILIAN_APP_KEY` 和对象存储 AccessKey 只写在本机 `.env.local`（已在 `.gitignore`），绝不进入 HTML、前端 JS 或提交记录。返回给页面的错误信息会脱敏并截断，不包含 Authorization、密钥或完整平台响应。`data/` 是运行期目录（审批记录与本地上传），同样不提交。
